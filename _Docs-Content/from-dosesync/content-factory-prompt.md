# Content Factory — Универсальный промт для размножения контента

## Когда использовать

После создания финального сценария длинного видео. Вставляешь этот промт в чат вместе со сценарием — получаешь 21 единицу контента за один запрос.

## Промт

```
Ниже — финальный сценарий моего длинного видео. Твоя задача — размножить его на контентные единицы для всех платформ. Делай всё за один раз. Не сокращай, не пропускай блоки. Каждая единица контента — копипаст-готовая.

Перед началом работы изучи сценарий и определи:
- Кто автор (имя, сфера деятельности, тон подачи)
- Кто целевая аудитория
- Какой разговорный регистр использует автор (сленг, обороты, характерные фразы)
- Какая основная проблема раскрывается в видео
- Какие личные истории и кейсы приводятся
- Какой философский или ценностный слой заложен

Сохрани стиль автора во всех текстах. Не исправляй его речевые особенности — это голос бренда.

Обязательные правила для ВСЕХ текстов:
- Сохраняй разговорный регистр автора: его сленг, обороты, характерные выражения
- Сохраняй обращение к аудитории, которое автор использует в сценарии (на «ты» или на «вы»)
- Пропускай каждый текст через антиИИ-фильтр: никаких «стоит отметить», «необходимо подчеркнуть», «в мире/сфере», деепричастных оборотов-пустышек (подчёркивая, демонстрируя, символизируя), канцелярита, Title Case в русских заголовках, эмодзи в заголовках, отрицательных параллелизмов «не просто X, а Y», группировок по три, хеджирования (можно предположить, что, возможно), подхалимского тона, промо-языка (непревзойдённый, захватывающий дух)
- Кавычки — «ёлочки», внутри — „лапки"
- Если в сценарии есть философский, ценностный или мотивационный слой — сохрани его во всех единицах контента
- Финальный антиИИ-проход: перед выдачей каждого текста спроси себя «что здесь выдаёт ИИ?» и перепиши проблемные места

БЛОК 1. СТАТЬЯ для Яндекс Дзен / VC.ru / ВКонтакте
Объём: 1500–2500 слов.
Структура:
1) Заголовок — по формуле ВИСП (Выгода + Интрига + Срочность + Причастность). Цифры, название инструмента или темы, без эмодзи. Дай два варианта на выбор.
2) Лид (первые 2 предложения) — хук из сценария, адаптированный под текстовый формат. Задача: зацепить за первые 3 секунды чтения. Поднять боль аудитории.
3) Постановка проблемы — одна проблема из видео. Усугубление: что будет, если не решить? Конкретные цифры или ситуация из жизни целевой аудитории.
4) Основная часть — разбить на 3–5 подзаголовков. Каждый подзаголовок решает подпроблему. Внутри каждого блока: боль → пример → решение. Вставить одну личную историю из сценария (если есть).
5) Философский / ценностный блок — если в сценарии есть притча, цитата, метафора или мотивационный посыл — вынеси его в отдельный абзац ближе к концу. 2–3 предложения. Свяжи с темой статьи.
6) Заключение + CTA — резюме в 2–3 предложения. Призыв подписаться на основной канал автора. Если автор использует подписную фразу — поставь её в финале.
Тон: как в сценарии. Экспертный, но без менторства сверху. Как рассказ коллеги, который делится находками.

БЛОК 2. ДЕСЯТЬ ТРЕДСОВ (Threads)
Каждый тредс — самостоятельная микроединица. Длина: 3–7 предложений (до 500 знаков).
Структура каждого тредса:
- Строка 1: хук — вопрос, провокация, цифра или личный опыт.
- Строки 2–5: содержание — одна мысль, один инсайт из сценария. Конкретика: цифры, названия инструментов, примеры.
- Последняя строка: CTA — чередуй между тредсами: «Подписывайтесь — буду делиться ещё», «Сохраняйте, пригодится», «Напишите в комментариях, как вы решаете эту задачу», «Больше разборов — в моём канале [название]».

Распределение десяти тредсов по темам:
1. Главный инсайт видео (самая сильная мысль)
2. Статистика или цифра из видео
3. Ошибка, которую допускает целевая аудитория
4. Лайфхак или конкретный приём из видео
5. Личная история из сценария (сторителлинг)
6. Сравнение «до и после» или «было — стало»
7. Философская или мотивационная мысль из сценария
8. Разрушение мифа или возражения скептиков
9. Чек-лист или мини-гайд (3–5 шагов)
10. Провокационный тредс — мнение, с которым не все согласятся

БЛОК 3. ПЯТЬ СЦЕНАРИЕВ ДЛЯ REELS / YOUTUBE SHORTS
Хронометраж: 30–60 секунд каждый (80–150 слов).
Структура каждого рилса:
- Секунды 0–3: хук-стоппер — фраза, которая останавливает скролл.
- Секунды 3–7: поднятие боли — в чём проблема зрителя? Одно-два предложения.
- Секунды 7–25: основная часть — решение в 2–4 предложениях. Конкретный инструмент, приём, кейс. Без воды.
- Секунды 25–30: CTA — чередуй: «Подписывайтесь — покажу ещё [N] таких приёмов», «Сохраняйте это видео», «Полный разбор — ссылка в шапке профиля», «Напишите в комментариях [вопрос]».
Режиссёрские пометки в скобках: (СМОТРИТ В КАМЕРУ), (ПОКАЗЫВАЕТ ЭКРАН), (ПАУЗА), (АКЦЕНТ — повысить голос), (ЖЕСТ).

Распределение пяти рилсов:
1. Главный инсайт видео — «шок-контент»
2. Ошибка + правильный подход
3. Лайфхак за 30 секунд (пошагово)
4. Мини-история из сценария (сторителлинг)
5. Философская или мотивационная мысль + практический вывод

БЛОК 4. ПЯТЬ ТЕКСТОВЫХ ПОСТОВ для Telegram / VK / Макс
Объём: 500–1000 знаков каждый. Чистый текст — без картинок.
Структура каждого поста:
- Строка 1: опенинг-хук — останавливает скролл в ленте.
- Строки 2–6: основная часть — одна мысль, один инсайт. Разговорный стиль автора. Короткие абзацы (1–2 предложения). Конкретика: цифры, названия, кейсы.
- Финал: CTA — чередуй: «Напишите в комментариях, как вы решаете эту задачу», «Ставьте реакцию, если хотите разбор [темы]», «Полный разбор — в видео на канале: [ссылка]», «Подписывайтесь на [канал] — там все ссылки и материалы».

Распределение пяти постов:
1. Анонс видео — интрига без спойлеров
2. Инсайт из видео + личное мнение автора
3. Кейс или пример из сценария
4. Философская или мотивационная мысль, привязанная к теме
5. Вовлекающий пост: вопрос к аудитории или мини-опрос
```
