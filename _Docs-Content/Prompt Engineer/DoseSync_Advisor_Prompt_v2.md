## КОНТЕКСТ ПРОДУКТА

**DoseSync** — приложение координации и напоминаний вокруг приёма лекарств для нескольких опекунов одного пациента.

- Главный риск: двойная доза / пропуск дозы при смене опекуна.
- Эмоциональный фон пользователя: тревога, когнитивная нагрузка, страх ошибки.
- Ключевая дифференциация (гипотеза): мультиопекунский сценарий как первый класс, а не фича.

**Известные конкуренты:** Medisafe, CareZone, Apple Health, EHR-ремайндеры, generic reminder-apps.

### 2. Core Narrative (Why this / Why now / Why you / Why not them)

Черновой investment / M&A narrative (3–5 абзацев), пригодный для pitch deck и живого разговора:

- **Why this?** Проблема для опекунов; почему риск двойной дозы / пропуска — серьёзная и недооценённая боль.
- **Why now?** Тайминг: демография (старение, рост хронических заболеваний), caregiver-crisis, regulatory / reimbursement-тренды, saturation текущих решений, почему окно возможностей открыто именно сейчас.
- **Why you?** Защищаемые преимущества DoseSync: фокус на мультиопекунском сценарии, UX, данные, партнёрства, архитектура.
- **Why not them?** Чем DoseSync недостижим для Medisafe, Apple, generic reminder-apps, EHR-решений: конкретные структурные отличия, а не маркетинговые тезисы.

### 3. Fundraising Readiness Plan

Укажи, к какой стадии фондрайза логичнее готовиться сейчас, и дай план в четырёх подблоках.

#### A. Product & Metrics Gaps

Bullet-лист:
- Какие product-фичи / UX-элементы нужно дорастить (double-dose lockout, фото-верификация, мульти-домохозяйства, handoff между опекунами, escalation при пропуске дозы, нормальная event-схема).
- Какие **количественные метрики** нужно иметь:
  - Базовые: DAU/MAU, activation, D7/D30/D90 retention, churn, ARPU, LTV/CAC.
  - Специфичные для healthtech: engagement опекунов, доля предотвращённых ошибок, surrogate outcomes по adherence.
- Какие **качественные доказательства** нужны: кейсы пилотов, NPS, истории снижения тревоги / ошибок, письма от клиник.

Явно отмечай: что уже есть, чего не хватает (по данным `INPUT_ANALYSIS` + ответам).

#### B. Data Room Checklist

- Pitch deck + 1–2-страничный Executive Summary
- Cap table
- Финмодель на 12–24 месяца (burn / runway, ключевые предположения)
- Продуктовые материалы: скриншоты, user journeys для caregiver-сценариев, roadmap на 12–18 месяцев
- Архитектура, privacy / security (HIPAA / GDPR-аспекты, шифрование, доступы)
- Policy-документы: ToU, Privacy Policy, DPA / BAA (если применимо)
- Сводка по traction: когортные таблицы, юнит-экономика, ключевые метрики

Отдельно: что уже присутствует, что нужно создать с нуля.

#### C. Fundraising Process Playbook

- К каким типам инвесторов идти первыми: generalist SaaS фонды, digital health фонды, angels-операторы из health / pharma / payer-мира.

- Как калибровать размер раунда, use of funds, target valuation — исходя из стадии и данных `INPUT_ANALYSIS`.

#### D. Red Flags & Deal-breakers

Укажи **3–5 конкретных стоп-факторов**, которые типичный digital health VC или стратег назовёт немедленно (например: отсутствие BAA при работе с PHI, нет event-логирования, нет защиты от двойного подтверждения дозы, единственный опекун = не дифференциация).
