# Тест-план: DoseSync v1.0 | iOS

**Версия плана:** 1.0
**Дата:** 2026-04-03
**Роль:** Senior QA Engineer (iOS)
**Приложение:** DoseSync — трекер приёма лекарств
**Платформа:** iOS 16 / 17 / 18 | iPhone 12, 14, 15 Pro
**Методология:** CIRCUS MATTA + 6 характеристик качества требований

---

## 1. Цель тестирования

Убедиться, что DoseSync v1.0 корректно выполняет все заявленные функции, безопасно работает с медицинскими данными пользователя, соответствует Apple HIG и готова к публикации в App Store.

> **Критически важно:** приложение медицинского назначения. Ошибка в уведомлении о приёме препарата — прямой вред здоровью.

---

## 2. Область тестирования

### В области (v1.0)
- Онбординг (первый запуск)
- Управление препаратами (CRUD)
- Расписание и дозировка
- Push-уведомления (локальные)
- Ежедневный экран приёма доз
- История за 30 дней
- Настройки приложения
- Разрешения iOS (Notifications, HealthKit)
- Обработка ошибок и edge cases

### Вне области (v1.0, отложено)
- Синхронизация с iCloud
- Многопользовательский режим / опекунство
- Интеграция с аптеками / заказ препаратов
- Apple Watch companion app
- Экспорт данных в PDF

> **Принцип Необходимости:** не тестируем то, что не в релизе. Включение несуществующего функционала — ошибка полноты.

### 4.3. Push-уведомления (критический модуль)

| ID | Шаг | Ожидаемый результат | Тип |
|----|-----|---------------------|-----|
| NOTIF-01 | Уведомление в заданное время (±10 сек) | Текст: «[Название]: пора принять [доза]». Тап → Today view с нужным препаратом | MAN |
| NOTIF-02 | Уведомление при закрытом приложении (killed) | Приходит в заданное время, тап запускает приложение на нужном экране | MAN |
| NOTIF-03 | Уведомление при активном приложении (foreground) | In-app баннер; системное уведомление НЕ дублируется | MAN |
| NOTIF-04 | Действия: «Принял» / «Пропустить» | «Принял» → доза отмечена без открытия приложения; «Пропустить» → отмечена как пропущенная | MAN |
| NOTIF-05 | Изменение системного времени вручную | Уведомления перепланируются корректно, без дублирования | MAN |
| NOTIF-06 | Переход на летнее/зимнее время (DST) | Уведомления не сдвигаются на 1 час *(уточнить: UTC или localTime?)* | MAN |
| NOTIF-07 | Уведомления отключены в системных настройках | Предупреждение в приложении + кнопка «Открыть настройки» → Settings → DoseSync | MAN |
| NOTIF-08 | 10 препаратов × 3 приёма = 30 уведомлений | Все 30 запланированы (iOS лимит: 64); поведение при >64 задокументировано | AUTO |

## 5. Edge Cases

| ID | Сценарий | Ожидаемый результат |
|----|----------|---------------------|
| EC-01 | Первый запуск без интернета | Работает локально, нет спиннеров, нет крашей |
| EC-02 | Режим «Не беспокоить» / Focus Mode | Приложение не обходит системный DNT *(уточнить поведение в ТЗ)* |
| EC-03 | Принудительное закрытие во время сохранения | Данные не повреждены (транзакционность) |
| EC-04 | Смена часового пояса (перелёт) | Расписание пересчитывается корректно |
| EC-05 | Low Power Mode | Уведомления продолжают работать |
| EC-06 | Dynamic Type XXL | Текст не обрезается, UI не ломается |
| EC-07 | Dark Mode | Все экраны корректны, нет невидимого текста |
| EC-08 | Landscape orientation | Уточнить в ТЗ: поддерживается? Если нет — заблокировать |
| EC-09 | 2 препарата с одинаковым временем уведомления | Оба уведомления приходят, ни одно не теряется |

## 10. Критерии входа в тестирование (Entry Criteria)

- [ ] Сборка задеплоена на TestFlight
- [ ] Smoke-тесты прошли (не менее 90% AUTO)
- [ ] ТЗ согласовано с разрешёнными «белыми пятнами»
- [ ] Тестовые устройства доступны (iPhone 12 / 14 / 15 Pro)
- [ ] Среда тестирования настроена (тестовые аккаунты, симулятор)

---

## 11. Критерии выхода из тестирования (Exit Criteria)

- [ ] 100% критических тест-кейсов выполнено
- [ ] 0 открытых багов уровня Critical / Blocker
- [ ] ≤ 3 открытых бага уровня Major (с планом фикса)
- [ ] Smoke AUTO-тесты: 100% pass
- [ ] Производительность: все метрики в норме
- [ ] Accessibility: VoiceOver без Blocker-багов
- [ ] Проверка App Store Guidelines (ATS, Privacy Manifest)
