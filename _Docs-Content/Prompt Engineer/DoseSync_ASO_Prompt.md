# DoseSync — iOS ASO Full Package Prompt
**Version:** 1.0 | **Platform:** App Store (iOS, EN/US) | **Method:** NovaSapiens Research

---

## PROMPT

```
APP CONTEXT:
- App Name: DoseSync
- Category: Health & Fitness / Medical
- Core function: Medication intake tracker — reminders, schedules, dose logging, adherence history
- Target users: Adults managing chronic conditions, elderly patients, caregivers, parents tracking family medications
- Platform: iOS App Store | Market: English (US primary)

iOS ASO GROUND RULES — apply throughout:
- Apple indexes for search ranking: App Name (≤30 chars), Subtitle (≤30 chars), Keywords field (≤100 chars)
- Description is NOT indexed — it serves conversion only
- Keywords field format: comma-separated, zero spaces after commas (each space wastes a character)
- Words already in App Name or Subtitle must NOT appear in the Keywords field (duplicate = wasted slot)
- App Name keywords rank 2× stronger than Keywords field keywords

---

PHASE 1 — KEYWORD STRATEGY
Complete this phase fully before writing any copy.

Slot A — Intent mapping:
List EXACTLY 20 search queries users type when looking for a medication tracker app.
Group them into three clusters:
  • Primary: medication reminders and scheduling (8 queries)
  • Secondary: health tracking and adherence (6 queries)
  • Adjacent: caregiver tools, chronic illness management, refill reminders (6 queries)

Slot B — Priority scoring:
For each of the 20 queries, calculate a Priority Score using:
  Score = Search Volume Potential (1–10) × Relevance to DoseSync (1–10) ÷ Estimated Competition (1–10)
Surface the TOP 8 queries ranked by score. Show your math.

Slot C — Character budget allocation:
Map the top 8 queries to their optimal placement:
  • App Name slot: the single highest-volume term (must fit in ≤30 chars total with brand name)
  • Subtitle slot: second-priority cluster (≤30 chars, zero overlap with App Name)
  • Keywords field: remaining longtail and adjacent terms (≤100 chars total, comma+no-space format)
Confirm: zero word overlap across all three fields before proceeding to Phase 2.

IMPORTANT: Write out all 20 queries and all 8 scores in full. Do not summarize or compress Phase 1.

---

PHASE 2 — ASO PACKAGE GENERATION
Generate each element using the keyword allocation from Slot C.

1. APP NAME — max 30 characters
   Format: [Brand] – [Primary Keyword]
   Use the highest-volume term from Slot C. Count characters explicitly.

2. SUBTITLE — max 30 characters
   Target the second-priority cluster from Slot C.
   Complement the App Name — add new keyword coverage, zero word repetition.
   Count characters explicitly.

3. KEYWORDS FIELD — max 100 characters total
   Use comma-separated format with zero spaces after commas.
   Draw exclusively from the Keywords field allocation in Slot C.
   Include only words absent from App Name and Subtitle.
   Count total characters explicitly.

4. PROMOTIONAL TEXT — max 170 characters
   Lead with the single strongest user benefit (outcome, not feature).
   Tone: warm, direct, practical. This field is NOT indexed — write for human conversion.

5. DESCRIPTION — max 4000 characters
   Structure in this exact order:

   [HOOK — lines 1–3, visible before "more" tap]
   Open with the #1 user pain point. Introduce DoseSync as the solution.
   Close the hook with one specific, concrete benefit claim.

   [CORE FEATURES — exactly 5 items]
   Format each as: [User outcome] — [Feature mechanic]
   Lead with what the user gains, follow with how the feature delivers it.

   [WHO IT'S FOR — 2–3 sentences]
   Name the target user segments explicitly. Help the right person self-identify.

   [SOCIAL PROOF]
   [PLACEHOLDER — insert: X stars · Y ratings · "Best medication app" — reviewer name/source]

   [CLOSING CTA]
   Direct download prompt. End with a single trust signal (privacy, free to start, or ease of setup).

---

PHASE 3 — SELF-VERIFICATION
Run every check before producing the final output.
If any check is ✗, fix the issue and recheck before proceeding.

  □ App Name ≤ 30 characters ✓/✗
  □ Subtitle ≤ 30 characters ✓/✗
  □ Keywords field ≤ 100 characters ✓/✗
  □ Zero words repeated across App Name + Subtitle + Keywords field ✓/✗
  □ Keywords field contains zero spaces after commas ✓/✗
  □ Description hook opens with a user pain point (not a feature list) ✓/✗
  □ Description contains exactly 5 feature items ✓/✗
  □ First 3 lines of Description readable as a standalone value statement ✓/✗

All checks must show ✓ before output.

---

FINAL OUTPUT FORMAT

Present the complete ASO package in this structure:

APP NAME: [text] (X/30 chars)
SUBTITLE: [text] (X/30 chars)
KEYWORDS: [text] (X/100 chars)
PROMO TEXT: [text] (X/170 chars)

DESCRIPTION:
[full text, no truncation]

---
KEYWORD STRATEGY NOTE:
[4–6 sentences explaining: which keywords you prioritized and why, how you allocated them across the three indexed fields, and what longtail opportunities you targeted in the Keywords field]
```

## NovaSapiens — Checklist применённых техник

| Техника | Применение |
|---|---|
| **CQO-порядок** | Контекст → Анализ (Фаза 1) → Вывод (Фаза 2) → Формат |
| **SCoT-слоты** | Slot A / B / C в Фазе 1 — жёсткие forcing functions |
| **Числовые якоря** | "EXACTLY 20 queries", "TOP 8", "exactly 5 items", явный подсчёт символов |
| **Brevity Bias Fix** | "Write out all 20 queries in full. Do not summarize or compress." |
| **Позитивные инструкции** | "Include only words absent from..." вместо "не повторяй" |
| **Верификационный цикл** | Phase 3: все 8 чекбоксов, инструкция fix+recheck при ✗ |
| **≤3 формат-требования** | Каждая фаза — отдельный проход с узким фокусом |
| **Two-Tier Structure** | Фаза 1 (факты/цифры) → Фаза 2 (синтез копи) |
| **Антипаттерн #1 убран** | Нет "expert with 10 years" — только функциональный контекст |
| **Антипаттерн #5 убран** | Нет "don't repeat keywords" — только позитивная инструкция |
