# App Idea Hunter — Prompt v2.0
## Улучшен по методологии Nova Sapiens (10 уровней)

---

```
<контекст>
Рынок мобильных приложений в 2026 году: 6.3 млрд пользователей смартфонов, медианное приложение зарабатывает менее $50/мес после первого года, только 17% приложений достигают $1K/мес. Побеждают hyper-niche утилиты, решающие одну дорогую боль для узкой вовлечённой аудитории. Модель подписки даёт предсказуемый recurring revenue. AI, AR и on-demand сервисы — главные драйверы роста.

Я ищу идеи мобильных приложений с подписочной монетизацией и потенциалом $5,000+/мес чистого дохода в первые 6-12 месяцев после запуска.
</контекст>

<задание>
Проведи исследование по 5 категориям источников и найди РОВНО 10 оригинальных идей мобильных приложений, которые пока не реализованы или реализованы крайне слабо.

Источники для анализа:
1. Форумы и сообщества: Reddit (r/AppIdeas, r/SideProject, r/startups), Indie Hackers, Product Hunt — ищи повторяющиеся запросы пользователей, на которые нет достойного ответа
2. Отзывы App Store и Google Play: 1-3 звезды у популярных приложений — систематические жалобы, которые можно превратить в отдельный продукт
3. Тренды: восходящие поисковые запросы, новые API и технологии (AI, AR, HealthKit, on-device ML), законодательные изменения, создающие новые потребности
4. Профессиональные боли: задачи, которые специалисты решают вручную или через комбинацию 3+ инструментов
5. Демографические сдвиги: стареющее население, remote workers, Gen Z привычки, рост solo-предпринимательства

Для каждой идеи заполни ровно эти поля (atomic facts):
— Название (рабочее, 2-4 слова)
— Боль (какую конкретную проблему решает, для кого)
— Киллер-фича (одна уникальная функция, которая делает это приложение незаменимым — опиши механику в 2-3 предложениях)
— Почему сейчас (что изменилось в 2025-2026, что делает эту идею своевременной)
— Конкуренты (ближайшие существующие решения и их главная слабость)
— Путь к $5K/мес (ценовая модель подписки, сколько платящих пользователей нужно, реалистичный канал привлечения)
— Сложность разработки MVP (оценка: 1-5, где 1 = no-code за 2 недели, 5 = команда 3+ на 6 месяцев)
</задание>

<оценка_жизнеспособности>
После списка всех 10 идей — оцени КАЖДУЮ по 3 осям, используя дробные оценки (например, 7.3, не округляй до целых):

1. Рыночный потенциал (1.0-10.0): размер аудитории × готовность платить × частота использования
2. Defensibility (1.0-10.0): насколько трудно скопировать через 6 месяцев (сетевые эффекты, данные, привычка)
3. Founder-Market Fit для соло-разработчика (1.0-10.0): можно ли запустить MVP одному за 1-3 месяца

Якоря для калибровки:
— Оценка 2.0: приложение-фонарик — огромная аудитория, нулевая defensibility, нулевая монетизация
— Оценка 9.0: Notion в 2016 — болезненная проблема, сильный retention, network effects, сложно повторить

Итоговый рейтинг = среднее трёх оценок. Отсортируй 10 идей по убыванию.
</оценка_жизнеспособности>

<когнитивный_сброс>
СТОП. Перед финализацией ответа задай себе вопрос: «Есть ли РАДИКАЛЬНО другие категории приложений, которые я не рассмотрел? Есть ли идеи на стыке двух индустрий, которые неочевидны?»

Если найдёшь хотя бы 1 такую идею — добавь её в список как #11 (бонус) с пометкой [WILDCARD].
</когнитивный_сброс>

<формат_вывода>
Язык: русский.
Структура: таблица-саммари (название + боль + оценка) → затем развёрнутые карточки по каждой идее → финальный рейтинг.
После выполнения напиши: «✓ Все 10 идей (+ wildcard) готовы, отсортированы по жизнеспособности».
</формат_вывода>
```

## Что применено из методологии Nova Sapiens:

| Принцип | Где в промпте |
|---|---|
| **CQO-порядок** (Ур. 1.1) | `<контекст>` идёт первым — цифры рынка, задача, ограничения. Только потом задание |
| **Убрана абстрактная роль** (Антипаттерн) | Нет «ты профессиональный аналитик». Вместо этого — задачный фрейм с конкретными источниками |
| **SCoT-слоты** (Ур. 3.1) | 5 категорий источников = 5 обязательных слотов анализа. Фиксированные поля карточки = forcing function |
| **Числовой якорь** (Ур. 1.4, 5.1) | «РОВНО 10 идей» + финализирующая проверка «✓ Все 10 готовы» |
| **Дробные оценки + якоря** (Ур. 5.2-5.3) | 3 оси с шкалой 1.0-10.0 + два якорных примера (2.0 и 9.0) |
| **Когнитивный сброс** (Ур. 4.2) | Явный блок `<когнитивный_сброс>` с wildcard-идеей |
| **Two-Tier структура** (Ур. 6.2) | Atomic facts в карточках + synthesis в рейтинге |
| **Макс 3 требования к формату** (Ур. 2.3) | Формат минимален: язык + структура + финализация. Суть не задавлена форматированием |
| **Позитивные формулировки** (Ур. 2.2) | Используй → вместо «не используй». Везде сказано ЧТО делать, а не чего избегать |
