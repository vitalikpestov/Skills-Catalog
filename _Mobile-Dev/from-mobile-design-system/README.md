## Описание скилла (из WebSearch)

The Mobile Design skill transforms Claude into a specialized mobile architect capable of building high-performance, platform-respectful applications. It shifts the AI's focus from 'small desktop' thinking to true mobile-first constraints, incorporating touch psychology, Fitts' Law, and the ergonomic 'Thumb Zone.'

## Ключевые возможности

- **Touch-first UX** — на основе Fitts' Law и 44-48px минимум target standards
- **Platform-aware UI** — iOS HIG + Android Material Design 3
- **Security-first** — SecureStore, Keychain, EncryptedSharedPreferences
- **Performance** — React Native FlatList/FlashList, Flutter widgets

## Для кого

Разработчики React Native / Flutter / нативных приложений, которым нужны:
- Production-grade UX
- Battery-conscious logic
- Secure data handling
